# Microsoft 365 Group Administration Lab

## 🎯 Objective
To add a cloud user account to an existing group to assign corporate resource access.

---

## 📊 Environment & Administration Tools

| Tool Panel | Target URL | Operational Function |
| :--- | :--- | :--- |
| **Microsoft 365 Admin Center** | `://microsoft.com` | Web dashboard used to manage user profiles, track groups, and adjust resource allocations. |

---

## 🚀 Standard Operating Procedures

### Part A: Group Membership Assignment
1. Log into the administrative web portal dashboard at `https://://microsoft.com`.
2. Expand the left navigation menu and click **Teams & groups** > **Active teams & groups**.
3. Select the target group name item row (e.g., *Finance*) from the active directory listing to open its properties panel.

![Microsoft 365 Admin Center Groups Dashboard Displaying the Active Group Inventory List](images/01-m365-groups-list.png)

4. Switch to the **Members** tab inside the flyout properties panel card view and click **View all and manage members**.
5. Click the **Add members** button at the top of the interface.

![Microsoft 365 Group Members Panel Initializing the Add Members Configuration Prompt](images/02-m365-group-members-panel.png)

6. Type the employee profile name (**Marcus Vance**) into the search bar or select their checkbox from the directory listing.
7. Click the **Save** button (or **Add**) to append the user account directly to the group ledger.

![Microsoft 365 Admin Center Interface Saving the Updated User Membership Selection to the Group](images/03-m365-add-member-save.png)

---

## 🔍 Verification & Auditing

### Membership Inheritance Verification
1. Navigate back to **Users** > **Active users** in the left sidebar menu layout.
2. Search for and click on user **Marcus Vance** to expand his master property details.
3. Select the **Account** tab, locate the **Groups** section row, and verify that the target group name is explicitly listed, confirming successful membership assignment.

![Microsoft 365 Active Users Profile Summary View Confirming Group Membership Inheritance Success](images/04-m365-user-group-verification.png)
